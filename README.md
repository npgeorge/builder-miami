# Builder Miami · AI × Bitcoin

A local, host-led discussion experience for Thursday October 29, 2026. Open `dist/index.html` in a browser, or serve `dist` with any static HTTP server. No installation, API keys, external fonts or live model are required.

For localhost, double-click `Start Roundtable.command`, then open http://127.0.0.1:8048/. Keep its Terminal window open while presenting. If the site is already running, just open the URL; no second server is needed. Press Control-C in the server's terminal to stop it.

The screen offers five discussion areas with short case studies, progressively deeper questions, direct source links, a qualitative room mood check, a local notebook, and an optional count-up timer. Each case shows its context, source titles with media labels, and a plain-language explanation on the page. Source links open the original in a new tab; no intermediate source panel is required. It is designed for a 60–90 minute room conversation. There is no audience device flow or online voting.

Keyboard: M map; 1–5 topics; 6 all links; Q question-only mode; left/right prompt depth; E focus the first source link (restoring context if needed); N notes; F fullscreen; ? help. Escape closes dialogs or exits question-only mode. Browser fullscreen may also consume Escape.

Entering any of the five discussion areas always starts at Starting Point, including revisiting or clicking the active topic tab. The selected case within that area is retained. A sixth Links tab follows Connect and lists every source in a single vertical feed, grouped by area and case. Each row pairs the link and media type with a brief one-sentence summary; on narrow screens the summary sits beneath its link. The map also has an All links shortcut. This page reads the same source data as the discussions and includes the original Index brainstorm link, for 56 unique links in total. Map links and the 1–5 shortcuts follow the same rule.

Notes, moods, timer and visited areas are stored in the current browser's localStorage. Host tools can export notes as text or clear the session with an explicit second click. Nothing is sent to a backend. Use an extended display or print personal facilitator notes if you do not want the room to see the host panel.

Content and interaction code are in `dist/index.html`. The Greco-futurist theme is in `dist/assets/agora.css`; decorative generated artwork is stored locally in `dist/assets/satoshi-marble-wide.png`, with the edit prompt in `dist/assets/SATOSHI-WIDE-ARTWORK.md` (the previous artwork is retained). Keep the `dist` folder together when moving the experience. The `sources` and `topics` objects hold source capsules and prompts. The 14 case studies begin with a named product, event, study, disclosure or dispute; a separately labeled closing moonshot invites the room to propose an experiment. Its overview describes the published evidence; the opening question examines that case. Bigger Questions and Build Opportunities extend it into implications and experiments. Product claims, field studies, historical cases and reporting are explicitly labeled. Exact references not confidently identified are described in the host preparation panel rather than presented as verified news.

Each of the 15 discussion subsections has 3–5 direct references (51 unique main sources, plus four risk-related links), combining original material with practical guides and relevant background. Media labels distinguish videos, papers, demos and other formats. Broader context is identified in Host tools so it is not mistaken for corroboration of a specific incident. Some publishers may restrict automated access or require cookies. Source selection was checked against publisher pages and search-indexed publisher content. Before the event, review current claims and test fullscreen/question-only mode on the actual projector. Source links require internet; the experience itself works offline.
